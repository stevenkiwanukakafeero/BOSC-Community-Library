# Code of Conduct

## Our Pledge

We pledge to make participation in the BOSC Community Library project a respectful and harassment-free experience for everyone.

## Expected Behavior

- Use welcoming language
- Respect differing viewpoints
- Accept constructive criticism
- Focus on community growth

## Unacceptable Behavior

- Harassment
- Personal attacks
- Discrimination
- Trolling or insulting comments

## Enforcement

Project maintainers are responsible for enforcing this code of conduct and may remove inappropriate contributions.
