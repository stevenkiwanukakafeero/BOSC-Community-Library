# Contributing to BOSC Community Library

Thank you for contributing to the BOSC Community Library project.

## Contribution Process

### 1. Fork the Repository

Fork the repository and clone it locally.

### 2. Create a Branch

Create a new branch for your contribution.

Example:

```bash
git checkout -b feature/new-feature
```

### 3. Make Changes

Ensure your code follows project standards and is properly tested.

### 4. Commit Changes

Use professional commit messages.

Example:

```bash
git commit -m "feat: added searchable resource system"
```

### 5. Push to GitHub

```bash
git push origin feature/new-feature
```

### 6. Submit Pull Request

Open a pull request and describe your changes clearly.

## Coding Standards

- Maintain clean code structure
- Use meaningful file names
- Comment complex logic
- Avoid duplicate code

## Reporting Bugs

Use the issue templates provided in the repository.

## Community Standards

All contributors must follow the project's Code of Conduct.
