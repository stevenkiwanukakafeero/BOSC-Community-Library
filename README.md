
# BOSC-Community-Library

An open-source digital community library for organizing, sharing, and accessing educational resources through collaborative open-source development practices.

---

## Project Overview

The BOSC Community Library is a web-based open educational resource platform developed as part of the BSCT 3221 – Open Source Software final take-home examination.

The project demonstrates professional open-source software engineering practices including:

- Repository governance
- Branch-based development workflow
- Issue tracking and pull requests
- Community contribution standards
- Legal and sustainability analysis
- Responsive frontend development
- Dynamic JSON-based resource management

The platform allows users to browse, search, and filter educational resources through a modern interface while showcasing transparent and maintainable OSS project architecture.

## Search System

The project implements a dynamic JSON resource loading system using JavaScript fetch APIs. Educational resources are loaded from a structured JSON database and displayed dynamically on the interface.

Features include:

* Real-time search
* Category filtering
* Dashboard statistics
* Dynamic card generation

---

## Dashboard Features

The statistics dashboard provides:

* Total resource count
* Category count
* Beginner-level resource tracking
* Intermediate-level resource tracking

This improves usability and gives users quick insight into the library structure.

---

## Dark Mode System

The platform includes a persistent dark mode implementation using:

* JavaScript theme toggling
* CSS dark-mode classes
* LocalStorage for theme persistence

User preferences remain saved even after page refresh.

## Installation & Running the Project

### Clone Repository

```bash
git clone https://github.com/stevenkiwanukakafeero/BOSC-Community-Library.git
```

### Navigate Into Project

```bash
cd BOSC-Community-Library
```

### Run Local Server

```bash
python -m http.server 8000
```

### Open In Browser

```text
http://localhost:8000
```
